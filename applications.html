🔍 先認識這塊板子 2 顆晶片、1 條橋

LinkIt Smart 7688 Duo 的重點就在「Duo」——兩顆個性完全不同的處理器,由一條 UART 橋接起來:

  • 🧠 MT7688(藏在那塊印著產品名的金屬屏蔽罩下,旁邊是 128MB DDR2):跑 Linux,負責 WiFi、網路服務、USB、SD 卡,也是 MCP server 的家
  • 🎛️ ATmega32U4(屏蔽罩左邊那顆小 QFP 晶片):Arduino 相容,負責即時 I/O 和 類比輸入(MT7688 自己完全沒有 ADC!)——它的電源和燒錄都走左下那個「USB 電源 & MCU USB 埠」
  • 🌉 橋:兩顆晶片之間有一條板內 UART 走線,AI 下的指令穿過這條橋,就能讀到真實世界的類比訊號

本專案的 MCP server 提供 13 個工具:GPIO 讀寫、I2C、SPI、PWM、UART、I2S 音訊播放、ATmega ADC 橋接——AI 一句話就能呼叫。
